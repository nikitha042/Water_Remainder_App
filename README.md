💧 Water Reminder App

Overview

Water Reminder App is a web-based application developed using HTML, CSS, and JavaScript. It helps users track their daily water intake, calculate BMI, set hydration goals, and receive reminders to stay hydrated.

Features

👤 User Profile

- Enter user details
- Store data using Local Storage
- Personalized dashboard

📏 BMI Calculator

- Calculates Body Mass Index (BMI)
- Displays BMI on the dashboard

💧 Daily Water Goal

- Automatically calculates daily water intake goal based on weight

📊 Progress Tracking

- Track water consumed throughout the day
- Visual progress bar

📝 Water Intake History

- Records water consumption history with timestamps

🔔 Notifications

- Browser notifications for water reminders

🔄 Reset Function

- Reset daily water consumption and history

Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API

How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open "startpage.html".
4. Complete the user setup process.
5. Access the dashboard and start tracking water intake.
